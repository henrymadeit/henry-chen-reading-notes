# Dashboard 更新與安裝

本更新尚未部署。請依序完成以下步驟，並保留原專案備份。

## 1. 複製程式

將壓縮檔內的 `src`、`functions`、`server`、`migrations` 四個資料夾，以及 `astro.config.mjs`、`tsconfig.json`，複製到原網站專案根目錄。
選擇「合併資料夾」及「取代同名檔案」。不要先刪除原有資料夾。
`server` 是本次新增，必須一起放入。原本的 public、文章、密碼檔與 wrangler.jsonc 都沿用。

## 2. 新增資料表

在 VS Code 開啟原專案，在專案根目錄的終端機執行：

```powershell
npx wrangler d1 execute henryreads-comments --remote --file=./migrations/2026-10-16-readers.sql
```

這一步在正式留言資料庫新增 readers、reader_events、reader_likes 三張表，不修改舊留言或舊愛心總數。SQL 可重複執行。
這裡請執行指定檔案即可，不需要重新執行舊 migrations。

## 3. 建置與部署

```powershell
npm run build
```

只有建置成功後才執行：

```powershell
npx wrangler pages deploy dist --project-name henryreads --branch main
```

部署時請在專案根目錄執行，保留 `functions` 與新增的 `server` 資料夾，不能只上傳 dist。
密碼繼續使用 Cloudflare 現有的 ADMIN_PASSWORD，不用提供給任何人。

## 4. 驗收

1. 關於 → 原本的 About 或底部「站主管理」→ 登入。
2. 登入後有「回覆留言」與「Dashboard」，兩者可切換，也可登出。
3. 「回覆留言」列出既有留言與回覆，提供直接回覆及自己的文字修改，訪客文字不可修改。
4. 「Dashboard」顯示啟用後的讀者紀錄。站主登入期間的瀏覽與互動排除。
5. 用另一個未登入的瀏覽器開啟一篇文章、按愛心、留言，回到管理瀏覽器確認同一筆讀者紀錄顯示該暱稱。
6. 用第三個瀏覽器留下同名暱稱，確認顯示「老王1」等編號，公開留言仍是原暱稱。
7. 取消愛心後，後台目前文章愛心數會減少，足跡仍保留取消紀錄。
8. 登出後直接進入 /dashboard 或 /admin-comments 應回到登入頁，資料 API 未登入回應 401。
9. 分別用手機與電腦確認表格、閱讀足跡與回覆表單。

## 統計定義與限制

- 每一筆讀者代表一個瀏覽器 Cookie，不保證是一位真人；不同裝置分開。
- 第一次成功留言或回覆後，暱稱會連到該瀏覽器先前記錄的足跡。同名編號只在後台顯示。
- 此版本記錄文章頁開啟，不統計首頁及分類頁瀏覽；不記錄 IP 或瀏覽器指紋。
- 相隔超過 30 分鐘沒有活動，下一次互動算新來訪。未間隔 30 分鐘的重開仍算同次來訪。
- 「看過文章」為開啟過的不同文章數，不代表讀完；重新整理會增加開啟事件。
- 文章愛心欄是啟用後追蹤到的目前狀態；留言與回覆愛心則列在足跡。
- 舊有愛心總數與留言保留，不能可靠回推成過去的個人閱讀紀錄。
- Cookie 有效期一年；清除 Cookie、無痕模式或封鎖 Cookie 會產生不同或無法延續的紀錄。
- Cookie 到期不會自動刪除資料庫歷史。本版尚未加入歷史清理功能。
- 新增了關於頁的追蹤說明與頁尾說明連結。
- 若追蹤資料庫寫入失敗，原本成功的留言與愛心仍正常返回，不會要求讀者重送。

## 回復

如要還原，使用套用前的程式備份重新建置部署。三張新增資料表可先留著，舊程式不會讀取它們。
不要直接刪除舊留言表，也不要重設任何資料庫。
